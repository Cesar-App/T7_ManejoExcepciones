# Proyecto de Validacion de Estudiantes

## Descripción:

Aqui se estuvo haciendo un programa sencilo de validacion de campos con excepciones como el campo de el correo electronico y de la edad para que cada uno de esos campos sean validos y no haya un error por insercion de datos inadecuada

## Tecnologías Utilizadas:

* **Lenguaje:** C#
* **Herramientas / Framework:** Windows Forms (.NET Framework 4.7.2)
* **Entorno o IDE:** Visual Studio Community 2026.

## Uso o Ejecución:

1. Abrir el proyecto en Visual Studio Community 2026.
2. Ejecutar el sistema presionando F5 o desde el botón de ejecución.
3. Ingresar el nombre completo del estudiante.
4. Ingresar la edad en formato numérico.
5. Ingresar el correo electrónico válido.
6. Presionar el botón "Guardar" para validar y registrar la información.
7. Presionar el botón "Limpiar" para borrar los datos de los campos.
8. Presionar el botón "Salir" para cerrar la aplicación.
9. Va aparecer un mensaje de alerta para asegurar la finalizacion del programa, si se desea salir precionar "si"
